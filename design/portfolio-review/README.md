# VOC 중심 디자인 비교 시안

`Enterprise-Knowledge-Loop-단순화-비교시안.html`을 브라우저로 열면 시작합니다. 설치·서버·인터넷 없이 사용할 수 있습니다. 같은 폴더의 `index.html`은 소스 파일을 나눈 버전입니다.

- 개선 이유·메뉴 매핑·화면 배치·3분 시연: `디자인-개선안.md`
- 화면 이미지: `screenshots/`
- 브라우저 상호작용 점검: `verification.json`
- 점검 스크립트: `verify.cjs` (Playwright/Chrome 필요, 현재 작업 경로 기준)

## 사용

1. 첫 화면은 VOC 목록과 분류 확인입니다. ‘VOC 처리 시연’을 시작하면 각 장면의 설명을 확인할 수 있습니다.
2. 다음 장면으로 이동해도 승인·확정은 자동 수행되지 않습니다. 화면의 버튼을 직접 눌러 진행합니다.
3. VOC 확정 → 협업 회신·문서 근거·처리 결정 → 결과 검증·초안 제출 → 독립 검토·게시 → 부서 전달 → 다음 VOC에 활용 순서입니다.
4. 자유 탐색은 ‘시안 설정’에서 역할을 선택합니다. 새로고침하면 데이터가 초기화됩니다.

원본 상세 화면은 비교용 별도 상태로 실행됩니다. 단순화 화면과 데이터가 연동되지 않습니다. 이 파일은 실제 권한 통제나 AI 연결이 없는 가상 시안입니다. 원본 기획서와 루트 시안은 수정하지 않았습니다.

최신 캡처는 `screenshots/voc-*.png`입니다. 문서 검색과 권한 변경 시연은 문서함·처리 지식 검색·관리 메뉴에서 추가로 확인할 수 있습니다.
